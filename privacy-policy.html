🇫🇷 Politique de Confidentialité (Français)

1. Principe général et absence de collecte de données par l'éditeur

Physique Explicite Lab (« Edited by Salimprof ») est une application scientifique et pédagogique qui fonctionne sans serveur central de collecte :

  • Aucune donnée personnelle ni mesure capteur n'est collectée, transmise, stockée, vendue ou partagée par l'éditeur (Salimprof).
  • L'application ne demande aucun compte utilisateur, ne contient aucune publicité et n'intègre aucun SDK tiers d'analyse statistique, de suivi publicitaire, de télémétrie ou de rapport de plantage (absence totale de Firebase, Google Analytics, Crashlytics, Sentry ou SDK sociaux).
  • Toutes les expériences scientifiques intégrées ainsi que le module pédagogique « J'expérimente » et ses Quiz interactifs fonctionnent 100 % hors connexion : les signaux des capteurs sont traités exclusivement en mémoire vive locale sur votre smartphone.

2. Permissions Android (AndroidManifest.xml) et utilisation réelle vérifiée

Les permissions sensibles d'exécution (runtime permissions) ne sont demandées par Android qu'au moment précis où vous ouvrez une expérience qui requiert le capteur correspondant :

L'audio est traité en mémoire vive et s'arrête dès la mise en pause ou la fermeture de l'expérience (Experiment.onStop()).

3. Communications réseau, Accès à distance par Wi-Fi et expériences réseau

Aucun appel réseau automatique n'a lieu au lancement ni pendant les expériences locales. Une connexion réseau n'est établie que dans les 4 cas suivants, à l'initiative de l'utilisateur :

1. Accès à distance par Wi-Fi (RemoteServer.java / jlhttp) — Fonctionnement et risques :
  • Lorsque vous activez manuellement « Autoriser l'accès à distance » dans le menu d'une expérience, l'application démarre un serveur web HTTP local sur votre téléphone (port par défaut 8080), exposant les points /, /config, /get, /control, /export, /meta (caractéristiques matérielles de l'appareil et des capteurs, sans uniqueID), /time et /res.
  • Risques sur le réseau local (usesCleartextTraffic="true") : le flux HTTP local n'est pas chiffré (sans TLS/HTTPS) et ne comporte pas de mot de passe. Toute personne connectée au même réseau Wi-Fi (ou partage de connexion) connaissant l'adresse IP locale et le port affichés peut consulter les mesures en cours, télécharger les données (/export), lire le modèle de l'appareil (/meta) et démarrer/arrêter l'expérience (/control) tant que l'option reste cochée.
  • Recommandation : utilisez cette fonction uniquement sur un réseau local privé de confiance. Le serveur s'arrête immédiatement dès que vous quittez l'écran de l'expérience (Experiment.onStop()).
  • 2. Expériences réseau personnalisées HTTP / MQTT (NetworkConnection.java, Http.java, MqttClient.java) : si vous ouvrez un fichier d'expérience personnalisé (.phyphox) contenant un bloc <network>, l'application affiche une fenêtre d'avertissement bloquante (showDataPolicyInfo) détaillant l'adresse du serveur distant et les données demandées (mesures capteurs, microphone, GPS, métadonnées matérielles ou identifiant local haché NetworkMetadataUUID). Aucune donnée n'est envoyée sans votre accord explicite.
  • 3. Importation d'expérience par URL ou code QR : télécharge uniquement le fichier .phyphox ou .zip depuis l'adresse que vous avez saisie ou scannée.
  • 4. Ouverture volontaire de liens externes : ouvre dans votre navigateur externe les liens sur lesquels vous appuyez (dépôts GitHub, licence GNU GPL, documentation phyphox.org ou vidéos explicatives youtube.com).

4. Absence d'opérations en arrière-plan

L'application n'exécute aucun service d'acquisition en arrière-plan. Dès que vous quittez l'écran d'une expérience ou passez à une autre application (Experiment.onStop()), le serveur d'accès à distance (stopRemoteServer()) ainsi que tous les capteurs, le microphone, la caméra, le GPS, le Bluetooth et les connexions réseau (shutdownIO()) sont immédiatement arrêtés.

5. Stockage local, exportation et suppression des données

  • Stockage local privé : vos mesures enregistrées, expériences personnalisées, favoris et préférences restent dans l'espace interne privé de l'application. La sauvegarde automatique dans le cloud Android est désactivée (android:allowBackup="false").
  • Exportation à la demande : l'exportation (CSV, TSV, Excel .xlsx, image PNG, état .phyphox) ne se déclenche que lorsque vous appuyez sur Exporter ou Partager via le sélecteur Android (FileProvider non exporté).
  • Suppression : vous pouvez supprimer individuellement chaque état enregistré ou expérience personnalisée via Données → Ajouter ou importer des expériences (ou Paramètres → Gestion des données → menu de l'élément → Supprimer), ou effacer toutes les données via les paramètres Android (Applications → Physique Explicite Lab → Stockage → Effacer les données) ou en désinstallant l'application.

🇬🇧 Privacy Policy (English)

1. General Principle & No Data Collection by the Publisher

Physique Explicite Lab ("Edited by Salimprof") (com.salimprof.physiqueexplicitelab) is a scientific and educational Android application with no central data-collection backend:

  • No personal data or sensor measurements are collected, transmitted, stored, sold, or shared by the publisher (Salimprof).
  • The application has no user accounts, contains no advertisements, and includes no third-party analytics, advertising, telemetry, or crash-reporting SDKs (no Firebase, Google Analytics, Crashlytics, Sentry, or social SDKs).
  • All bundled scientific experiments as well as the "Let's experiment" (J'expérimente) educational module and its interactive Quizzes run 100% offline: sensor signals are processed solely in local RAM on your smartphone.

3. Network Calls, Wi-Fi Remote Access, and Custom Network Experiments

No automatic network calls are made on startup or during local experiments. Network communication occurs only in 4 user-initiated scenarios:

1. Wi-Fi Remote Access (RemoteServer.java / jlhttp) — Operation & Security Risks:
  • When you manually enable "Allow remote access" in an experiment's menu, the app starts a local HTTP server on your phone (default port 8080) exposing /, /config, /get, /control, /export, /meta (device model and hardware sensor specs, excluding uniqueID), /time, and /res.
  • Local Network Risks (usesCleartextTraffic="true"): Local HTTP traffic is unencrypted (no TLS/HTTPS) and has no password authentication. Anyone connected to the same Wi-Fi subnet (or mobile hotspot) who knows the displayed local IP address and port can view live measurements, download exported data (/export), read device/sensor hardware metadata (/meta), and start/stop the experiment (/control) while remote access is enabled.
  • Recommendation: Use Remote Access only on a trusted private local network. The server stops immediately when you uncheck the option or leave the experiment screen (Experiment.onStop()).
  • 2. Custom HTTP / MQTT Network Experiments (NetworkConnection.java, Http.java, MqttClient.java): Custom .phyphox files containing a <network> block display a mandatory blocking consent dialog (showDataPolicyInfo) disclosing the target server URL and requested data items (sensor readings, microphone, GPS, hardware metadata, or a locally generated per-service hashed UUID NetworkMetadataUUID) before any connection can occur.
  • 3. Importing Experiments via URL or QR Code: Connects only to the URL you entered or scanned to download the .phyphox or .zip file.
  • 4. Opening External Links: Opens external links you tap (GitHub repositories, GNU GPL license, phyphox.org wiki, or youtube.com help videos) in your external browser.

4. No Background Execution

The app runs no background data-collection services. As soon as the experiment screen leaves the foreground (Experiment.onStop()), the app immediately calls stopRemoteServer() and shutdownIO(), stopping all sensors, microphone, camera, GPS, Bluetooth, and network connections.

5. Local Storage, Data Export, and Deletion

  • App-Private Local Storage: Saved experiment states, custom experiments, favourites, and preferences stay in app-private internal storage. Cloud backup is disabled (android:allowBackup="false").
  • User-Initiated Export: Exporting data (CSV, TSV, Excel .xlsx, PNG screenshot, .phyphox state) occurs only when you explicitly invoke Export or Share via the Android Share sheet.
  • Deletion: You can delete individual saved states or custom experiments via Data → Add or import experiments (or Settings → Data management → item menu → Delete), or erase all data via Android Settings → Apps → Physique Explicite Lab → Storage → Clear storage or by uninstalling the app.
